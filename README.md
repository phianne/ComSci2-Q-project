#Project name: PhiCaBook; your payment buddy

#Project Description
PhiCaBook is a simple system designed to help small store owners manage their customers debts. It allows users to organize, store, update, and delete records easily, making debt tracking less stressful.

#Purpose
- Help store owners keep track of customer debts and recent updates
- Reduce confusion and errors in manual listing
- Provides a simple way to manage payments

#Features
- Add new customer debt records
- View all existing records
- Update customer information and payment status
- Delete records when debts are settled

#How it works
- Adds customer details and debtamount
- Save the record into the system
- Update records when payments are made
- Delete records once fully paid

#Target Users
- Small store owners

#Why PhiCaBook?
- Managing debts manually is sometimes confusing and time consuming. Our Project serves as your payment buddy, helping you stay organnize with your list of debts.

#Future Improvements
- Search and filter function
- Payment history tracking
- data security features
